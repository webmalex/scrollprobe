# Security Policy

ScrollProbe requests Accessibility permission and processes global scroll-wheel
events, so security reports deserve private handling.

Do not open a public issue for a suspected vulnerability or include private
Diagnostics logs in an issue. Use GitHub's **Report a vulnerability** action in
the repository Security tab. Include the affected version, impact, reproduction
steps, and the smallest necessary redacted evidence.

Ordinary compatibility problems and Protection failures belong in the public
bug-report template. Use `Copy Status` rather than an unreviewed Diagnostics
JSONL file whenever possible.
